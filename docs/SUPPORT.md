# Support

## Getting help

- Open an issue on GitHub for bugs or feature requests
- Check `USAGE_GUIDE.md` for the command reference
- Check `RULES_REFERENCE.md` for the rule catalog

## What we support

- Claude Code `.jsonl` session transcripts
- agentburn native `.json` run files
- Node.js >= 18

## What we don't do

- No LLM-based analysis or judgment
- No remote telemetry or data collection
- No hosted dashboard (local CLI only)
